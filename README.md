# 作品集网站 —— 使用说明

这个版本**不需要登录、不需要数据库**，但保留了完整的可视化编辑功能——点文字改文字、
点图片换图片、拖拽排序、调字体样式，都跟之前预览里一样。区别是：改动只存在你自己电脑
打开的这个页面里，改完需要**导出一次**，替换掉项目里的 `src/content.js`，再重新部署。

---

## 内容存在哪里

`src/content.js` 这一个文件，装着姓名、简介、联系方式、所有作品和所有排版设置。
`src/App.jsx` 是页面的显示逻辑，一般不用动。

---

## 怎么编辑内容

1. 在项目文件夹里执行：
   ```
   npm install
   npm run dev
   ```
2. 打开终端提示的网址，**在后面加上 `?edit=1`**，比如：
   ```
   http://localhost:5173/?edit=1
   ```
   不加这个参数，看到的就是干净的展示页面（没有任何编辑按钮）；加了之后右上角会出现工具栏。
3. 点右上角 **编辑页面**，就能开始编辑了：点文字改文字、点图片换图片、拖拽调整作品顺序、
   新建系列作品、调字体样式……跟之前预览里操作方式完全一样
4. 改完之后，点右上角的 **导出内容**（如果有改动还没导出，这个按钮会变成琥珀色提醒你），
   浏览器会下载一个 `content.js` 文件
5. 用下载到的这个文件，**替换掉项目里的 `src/content.js`**
6. 重新部署（见下面）

---

## 部署到 Vercel，拿到正式网址

1. 打开 https://vercel.com ，用 GitHub 账号注册/登录（免费）
2. 把这个项目文件夹上传到你自己的 GitHub 仓库
3. 在 Vercel 点 **Add New** → **Project**，选择这个仓库，其他都用默认设置，点 **Deploy**
4. 等一两分钟，拿到正式网址（比如 `your-name.vercel.app`），也可以绑定自己的域名

**重要**：正式网址默认打开是没有编辑按钮的干净展示页（因为没有 `?edit=1`）。如果你想在正式
网址上也能编辑（比如手机上打开线上网址直接改），打开 `你的网址/?edit=1` 就行——但要注意，
这种情况下改动依然只存在**你当时打开的那个浏览器标签页**里，别人看到的正式网站内容不会变，
你editMode 里改完了还是要点"导出内容"，把下载到的文件手动更新到 GitHub 仓库里，Vercel 重新
部署之后，所有人看到的才会更新。

简单说：**编辑 = 在本地（或者任何浏览器）预览修改效果 → 导出 → 替换文件 → 重新部署**，
这四步缺一不可，"导出"这一步不做的话，改动不会真的发布出去。

---

## 关于图片

上传的图片会转成一长串文字（base64）直接存进 `content.js` 里，不需要额外的图床，简单可靠，
缺点是图片存多了 `content.js` 文件会变大、加载会变慢。如果作品图片比较多或者都是高清大图，
建议改用外部图床链接（比如 Cloudinary、又拍云），content.js 里存链接就好。
